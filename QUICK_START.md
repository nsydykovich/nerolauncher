# Quick Start - Запуск Nero Launcher

## Шаг 1: Установка Java

Убедитесь, что у вас установлена Java (рекомендуется Java 17+):

```bash
java -version
```

Если Java не установлена:
- **Windows**: Скачайте с [oracle.com](https://www.oracle.com/java/technologies/downloads/) или используйте Chocolatey: `choco install openjdk17`
- **Linux**: `sudo apt install openjdk-17-jdk`
- **macOS**: `brew install openjdk@17`

После установки добавьте Java в PATH и пересоберите проект.

## Шаг 2: Сборка и запуск

```bash
# Установить зависимости (если не установлены)
pnpm install

# Собрать проект
pnpm build

# Запустить Tauri dev режим
pnpm tauri dev
```

## Шаг 3: Первый запуск

1. **Главная страница** - откроется с профилем "New Profile" (или любым существующим)
2. **Скачивание версии** (если не скачана):
   - Перейти на `/profiles/new` или `/profiles`
   - Выбрать версию (например, 1.21)
   - Нажать "Download"
   - Ждать окончания (может занять 2-5 минут)

3. **Запуск игры**:
   - Нажмите кнопку "Play" на главной
   - Лаунчер автоматически:
     - Скачает ассеты
     - Скачает библиотеки
     - Скачает и распакует natives
     - Запустит Minecraft

## Шаг 4: Решение проблем

### Ошибка: "launch_game missing required key profileId"

**Решение**: Убедитесь, что в героекшене есть активный профиль. Если нет - создайте новый:
```
1. Перейти на /profiles/new
2. Заполнить форму
3. Выбрать версию (1.21 recommended)
4. Нажать "Create Profile"
```

### Ошибка при скачивании ассетов

**Возможные причины**:
- Нет интернета - проверьте подключение
- API Mojang недоступен - повторите попытку позже
- Старая версия версия.json - заново скачайте версию

**Решение**:
```bash
# Удалить кеш ассетов и перескачать
rm -rf ~/.nerolauncher/assets
```

### Minecraft не запускается

**Возможные причины**:
1. **Java не найдена** - проверьте `java -version`
2. **Недостаточно памяти** - измените Xmx/Xms в settings
3. **Отсутствуют natives** - перескачайте версию

**Отладка**:
```bash
# Проверить логи в консоли браузера (F12)
# Проверить файлы
ls -la ~/.nerolauncher/versions/1.21/
ls -la ~/.nerolauncher/versions/1.21/natives/
```

## Шаг 5: Создать свой профиль

1. Перейти на `/profiles/new`
2. Заполнить поля:
   - **Name**: Название профиля (например, "Vanilla 1.21")
   - **Game Version**: Выбрать версию
   - **Mod Loader**: Выбрать (Vanilla, Forge, Fabric и т.д.)
   - **Java Version**: Выбрать Java (8, 11, 17, 21)
3. Нажать "Download" для загрузки версии
4. Нажать "Create Profile"
5. На главной нажать "Play" для запуска

## Шаг 6: Настройки Java (опционально)

Перейти на `/settings` → **Java Paths** для установки пользовательских путей к Java:

```
Java 8 Path: /path/to/java8/bin/java
Java 11 Path: /path/to/java11/bin/java
Java 17 Path: /path/to/java17/bin/java
Java 21 Path: /path/to/java21/bin/java
```

## Структура папок

```
~/.nerolauncher/
├── versions/         # Скачанные версии Minecraft
│   └── 1.21/
│       ├── 1.21.json       # Metadata версии
│       ├── 1.21.jar        # Client JAR
│       └── natives/        # Native библиотеки
├── libraries/        # Java зависимости (LWJGL и т.д.)
├── assets/          # Ассеты (текстуры, звуки)
│   ├── indexes/     # Asset index JSONs
│   └── objects/     # Сами ассет-файлы
└── settings.db      # База данных (профили, аккаунты и т.д.)
```

## Полезные команды

```bash
# Очистить весь кеш (потребуется переслачать)
rm -rf ~/.nerolauncher

# Очистить только ассеты
rm -rf ~/.nerolauncher/assets

# Очистить только одну версию
rm -rf ~/.nerolauncher/versions/1.21

# Смотреть размер папок
du -sh ~/.nerolauncher/*
```

## Поддерживаемые версии

- ✅ Release (1.0, 1.2.5, 1.21 и т.д.) - стабильные
- ✅ Snapshot (23w14a и т.д.) - еженедельные бета
- ✅ Old versions - старые версии

## Известные ограничения (пока нет)

- **Авторизация**: Сейчас используется stub аккаунт "Steve" (offline mode). Вы НЕ МОЖЕТЕ подключиться к официальным серверам.
- **Моды**: Установка модов требует дополнительной реализации

## Следующие шаги

После запуска игры:
1. Создать несколько профилей для разных версий/модов
2. Установить Microsoft аккаунт (когда будет реализовано)
3. Установить моды (когда будет реализовано)

**Если что-то не работает** - проверьте консоль браузера (F12) на ошибки и погуглите ошибку.
