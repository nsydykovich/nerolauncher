# Inter Font Files

Place Inter font files here:
- `inter.woff2` — Inter Regular (400)
- `inter-medium.woff2` — Inter Medium (500)
- `inter-semibold.woff2` — Inter SemiBold (600)
- `inter-bold.woff2` — Inter Bold (700)

Download from: https://rsms.me/inter/ or https://fonts.google.com/specimen/Inter

Once files are added, update `src/shared/config/fonts.ts` to switch from `next/font/google` (online) to `next/font/local` (offline).
